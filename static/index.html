🛡️ STVRAF Framework

Sovereign Threat Vector Risk Assessment Framework

A production-grade REST API backend implementing the STVRAF research framework — a Bayesian probabilistic model for assessing and tracking cyber-physical risk across fleet segments.

Built with FastAPI, SQLAlchemy, and Pydantic, this framework enables real-time threat probability calculations and composite risk scoring for fleet management systems.

📚 API Documentation (Swagger) 📖 API Documentation (ReDoc)

Key Features

  • Bayesian probabilistic risk modeling with prior and posterior probability tracking
  • Real-time telemetry ingestion and risk score updates
  • Fleet segment management with customizable impact severity and confidence discounts
  • RESTful API with comprehensive OpenAPI documentation
  • Production-ready with SQLAlchemy ORM and Pydantic validation
