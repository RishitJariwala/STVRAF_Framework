🛡️ STVRAF Framework

Sovereign Threat Vector Risk Assessment Framework

A production-grade REST API implementing a Bayesian probabilistic model for assessing and tracking cyber-physical risk across fleet segments. Built with FastAPI, SQLAlchemy, and Pydantic for robust, type-safe risk assessment.

✨ Key Features

🎯 Bayesian Risk Model
Calculate posterior probabilities with P(A|E) using observed telemetry evidence
📊 Fleet Segmentation
Track and assess risk across distinct operational fleet segments
🔍 Real-time Updates
Ingest telemetry data and dynamically update risk assessments
💾 Persistent Storage
SQLAlchemy ORM with SQLite backend for reliable data persistence
